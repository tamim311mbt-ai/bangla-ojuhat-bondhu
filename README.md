# Bangla Ojuhat Bondhu

Create a modern, fun, and interactive web application called "অজুহাত.কম (Ojuhat.com) - Smart Excuse Generator" completely in Bengali (Bangla) language.

Design & UI:
- Clean, vibrant, and playful UI using modern card layouts, soft gradients, and mobile-first responsive design.
- Use clean Bangla typography (like Hind Siliguri or Noto Sans Bengali).

Core Features:
1. Input Form:
   - Dropdown 1 ("কার জন্য অজুহাত?"): অফিসের বস (Boss), শিক্ষক (Teacher), বাবা-মা (Parents), বন্ধু (Friend), ভালোবাসার মানুষ (Partner).
   - Dropdown 2 ("কী সমস্যা হয়েছে?"): পৌঁছাতে দেরি হচ্ছে (Running Late), কাজ/অ্যাসাইনমেন্ট শেষ হয়নি (Work Incomplete), দাওয়াতে বা আড্ডায় যেতে পারছি না (Skipping Event), ফোন ধরতে পারিনি (Missed Call), টাকা ধার ফেরত দিতে দেরি (Delay in returning money).
   - Tone Selector ("অজুহাতের ধরন"): একদম বিশ্বাসযোগ্য (Realistic & Serious), হাস্যকর ও উদ্ভট (Funny & Weird), আবেগঘন (Emotional).
   - Optional text input: "অতিরিক্ত কোনো তথ্য যোগ করতে চাইলে লিখুন (ঐচ্ছিক)"
   - Big glowing CTA Button: "সেরা অজুহাত তৈরি করুন ✨"

2. Output Card:
   - Display a creative, well-written excuse in natural Bengali based on the selected inputs. (Build a rich, smart client-side database/logic with 50+ diverse, witty, and realistic Bengali excuses mapped to combinations so it works instantly without needing a paid backend API key).
   - Show a "বিশ্বাসযোগ্যতার হার (Believability Score)" progress bar (e.g., 85% বিশ্বাসযোগ্য).
   - Add a "সতর্কতা / টিপস (Pro Tip)" section (e.g., "এই অজুহাত দেওয়ার সময় গলার স্বর একটু নরম রাখুন").
   - Action Buttons: "কপি করুন 📋", "নতুন আরেকটি দেখুন 🔄", and "হোয়াটসঅ্যাপে পাঠান 📱".

3. Extra Fun Section:
   - "আজকের সেরা অজুহাত (Excuse of the Day)" banner at the bottom.
   - A small disclaimer in the footer: "শুধুমাত্র বিনোদনের জন্য তৈরি। ধরা পড়লে কর্তৃপক্ষ দায়ী নয়!"
